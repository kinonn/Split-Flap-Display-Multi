Split-Flap Baseline Curation (human-verified ground truth for the OCR benchmark)

The benchmark's reads.jsonl records what the display was commanded to show. When the display is what needs calibrating, the photo can differ from that command — so this tool curates baseline sets: copies of the photos with the content actually visible, entered (and corrected) by you. Entries start as pending (pre-filled with the previous run's read as a typing aid) and become verified when you save them; the benchmark only runs on verified entries by default.   ← back to the benchmark
